How It Works

Why the Airbag Light Stays On

When airbags deploy, the airbag control module records the crash and locks in crash data. Even after the airbags, seat belt pretensioners, and sensors are replaced, that stored data keeps the airbag light on.

Instead of buying a new module, a reset clears the crash data and stored codes so your original module works again, keeping the same part number and coding as the one that came with the car.

Before you send it: every deployed airbag, seat belt pretensioner, and crash sensor that needed replacing must already be replaced. We only reset the module. We don't clear codes to hide a missing, deployed, or faulty part.
